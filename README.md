# Codex Smart Routing

面向 Magpie 的 Codex 智能模型路由配置，以任务复杂度分配模型和推理强度，兼顾成本与质量。

## 路由表

| 任务 | 模型 | 推理强度 |
| --- | --- | --- |
| 阅读代码、文档、简单分析 | GPT-6 Luna | Medium |
| 简单修改、测试、常规部署 | GPT-6 Luna | High |
| 日常功能开发、UI、API | GPT-6.2 Sol | Medium |
| 需求分析、规划、排障、性能优化 | GPT-6.2 Sol | High |
| 大规模重构、反复失败的问题 | GPT-6.2 Sol | Extra High |
| 核心架构、极复杂工程问题 | GPT-6.2 Astra | High |

## 使用方法

1. 获取 [routing.json](routing.json)。
2. 核对 Magpie 中可用的模型 ID 和推理强度。
3. 在支持 routing-group JSON 的 Magpie 版本中导入配置，测试各类任务的实际路由结果。

## 设计原则

- 使用能够可靠完成任务的最低成本模型。
- 默认建议 Sol Medium；关键规划和复杂问题使用更强推理。
- 失败后升级模型，但必须由客户端或用户提供失败上下文；此 JSON 本身不实现自动重试或验证机制。
- 涉及生产环境、权限、安全或不可逆操作时，不应仅依据任务名称降低推理强度。

## 兼容性

本仓库是配置示例，不是独立路由程序。模型 ID、`xhigh` 参数、分类器可用性和导入方式尚未经过实际 Magpie 环境验证。成本收益也尚无统一实测数据。
